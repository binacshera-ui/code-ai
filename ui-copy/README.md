# Code AI UI preview

This preview renders the original React client with synthetic profiles, sessions, and conversation data. It does not forward requests to a backend. Non-GET requests are rejected. Real accounts, credentials, histories and server actions are unavailable.

Run `npm run dev:ui-copy` from the repository root to inspect it locally. The preview uses the original app styling and responsive layout. Configure any public hosting separately; no operator hostname or deployment path is included in the source.
